DraveMedia

Snelgids · Een alles-in-een mediaspeler met eigen mediaserver.

1. Wat is het?

Met DraveMedia speel je muziek en video af en bekijk je foto's. Je kunt je media ook delen met andere apparaten in huis, zoals je telefoon. Daarnaast maakt DraveMedia een speler die je op een eigen website kunt zetten.

2. Starten

  1. Pak de download-zip uit in een map naar keuze. Houd alle bestanden in die map bij elkaar.
  2. Dubbelklik op DraveMedia.exe.
  3. De eerste keer downloadt DraveMedia vanzelf FFmpeg (ongeveer 80 MB). Je ziet een voortgangsbalk. Hiervoor heb je internet nodig.
  4. Kies links een onderdeel: Speler, Afbeeldingen, Server of HTML5.

9. Tips

  • Open op je telefoon het adres van de server (zelfde wifi). Dan speelt alles achter elkaar af, als een radio.
  • Op de serverpagina kun je kiezen voor Speel alles, Herhaal alles en Shuffle.
  • Zet een Toegangscode als je de server via internet bereikbaar maakt.
  • Speelt een video niet? Probeer de Backend "VLC (alle formaten)".

10. Als iets niet werkt

Windows zegt "Windows heeft uw pc beveiligd".Klik op "Meer informatie" en dan op "Toch uitvoeren".
De FFmpeg-download lukt niet.Controleer je internet of firewall. Zonder FFmpeg speelt alleen wat de browser zelf aankan.
Mijn telefoon vindt de server niet.Zorg dat telefoon en pc op dezelfde wifi zitten. Sta DraveMedia toe in de Windows-firewall.
VLC werkt niet.Installeer VLC op je pc. Zonder VLC gebruikt de app vanzelf "Systeem (Qt)".
Installeren als app lukt niet op de telefoon.Dat kan alleen via HTTPS met een eigen domein. Wis eventueel de site-gegevens in de browser en probeer opnieuw.

11. Waar staan mijn gegevens?

Instellingen staan in dravemedia_config.json naast het programma. FFmpeg komt in de submap ffmpeg naast het programma.
